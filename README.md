## Lab Questions

###  Why can we not just use structural Verilog to implement latches?
We cannot use it because structural latches rely on combinatorial feedback loops.

### What is the meaning of always @(*) in a sensitivity block?

It tells the simulator to automatically include every signal that is read inside the block.

### What importance is memory to digital circuits?

It transforms simple calculators into systems that can store information run programs and make decisions based on past events.
